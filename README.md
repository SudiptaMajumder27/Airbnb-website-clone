🌍 WanderLust – Airbnb Clone
WanderLust is a full-stack web application that allows users to list, view, and review travel accommodations—just like Airbnb. Users can register, log in, create new listings with images, edit or delete them, and leave reviews on others' listings.

🚀 Live Demo
-[https://airbnb-website-clone-1.onrender.com]

🛠️ Tech Stack
Frontend: EJS, Bootstrap 5, Vanilla JS

Backend: Node.js, Express.js

Database: MongoDB (with Mongoose ODM)

Authentication: Passport.js (LocalStrategy)

Cloud: Cloudinary for image uploads

Hosting: Render.com

Map Integration: Mapbox API


📸 Features
🔐 User Authentication (Register/Login/Logout)

🏡 CRUD operations for listings

📷 Image upload support via Cloudinary

📍 Interactive Map for locations

⭐ Add, edit, delete reviews for listings

🔒 Route protection for ownership and authorization

⚠️ Flash messages for feedback and errors

📁 Clean and modular code structure



🧑‍💻 Setup Instructions
Prerequisites:

Node.js (v18+)

MongoDB Atlas account

Cloudinary account



Install dependencies
-npm install

.env
-SECRET=your-session-secret
-ATLASDB_URL=your-mongodb-atlas-connection-string
-CLOUDINARY_CLOUD_NAME=your-cloud-name
-CLOUDINARY_API_KEY=your-api-key
-CLOUDINARY_API_SECRET=your-api-secret

 Run the app locally
 -npm start
